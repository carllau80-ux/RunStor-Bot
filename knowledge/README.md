# 预置知识库文档

这个目录里的 Markdown 会**随部署一起安装**（`make deploy` → `/usr/share/backup-restore-agent/knowledge`），
服务启动时自动同步进知识库（缺什么补什么）—— 部署完就能直接用，不必手工导入。

## 怎么加自己的文档

1. 把 `.md` 文件放进 `knowledge/zh/`（或 `knowledge/en/`，目录可以任意建，会递归扫描）；
2. `make deploy`。

也可以不走代码仓库：直接把文件放到服务器上的预置目录，然后
`systemctl restart backup-restore-agent`。

## 同步规则（刻意保守，不跟操作者抢控制权）

| 情况 | 行为 |
|---|---|
| 知识库里没有同名文档 | 导入 |
| 有同名文档，且它也是预置的 | 内容不同就更新（升级时手册跟着刷新） |
| 有同名文档，是操作者自己导入的 | **不动它**（你的版本优先），启动日志里记一条 |
| 你删掉了某个预置文档 | 记住名字，**以后不再补回来** |

想让某个预置文档"归自己管"：在界面上重新导入一次同名文件即可 —— 之后同步就不再碰它。

## 现有文档

中英各一份：`zh/` 与 `en/`。检索会按语言自然命中对应那份。
